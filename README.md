# Atelier Nineteen — Showcase Studio

A single-page React portfolio that transforms into five independent, interactive demo websites: interior architecture, fragrance e-commerce, children’s events, Japanese hospitality, and premium real estate.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Stack

React 19, TypeScript, Vite, Framer Motion, Lucide icons, and brand-specific responsive CSS.

Photography is loaded from Unsplash and therefore requires an internet connection.
